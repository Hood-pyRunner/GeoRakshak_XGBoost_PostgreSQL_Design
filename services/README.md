# GeoRakshak Services

Planned backend modules:

- `ingestion/`: weather, rainfall, sensor, satellite, and community-report adapters.
- `risk-engine/`: feature generation, baseline rules, and XGBoost inference.
- `alert-service/`: SMS, IVR, siren, public-address, push, and delivery tracking.
- `admin-api/`: users, roles, zones, verification, audit logs, and authority workflows.
